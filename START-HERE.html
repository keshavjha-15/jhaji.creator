jhaji.creator

One download package for laptop and mobile · Version 2.0

Laptop browser extension

Extract ZIP → open chrome://extensions or edge://extensions → enable Developer mode → Load unpacked → choose the extension folder.

Android live extension

Use a mobile browser that explicitly supports extensions. Open its extension manager and follow its local-install instructions. Standard Chrome Android does not support desktop extensions.

Android / iPhone app-style PWA

Host the contents of the pwa folder on HTTPS. Open the website on your phone and choose Install app / Add to Home Screen. iPhone: Safari → Share → Add to Home Screen.

Important

The PWA is a rating planner and cannot control another browser tab. Live dropdown filling requires the extension in a compatible browser. The extension never submits feedback automatically.

See README-UNIVERSAL.md for complete instructions.
